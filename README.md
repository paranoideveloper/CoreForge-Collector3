# CoreForge Collector 3

Auto-updated subscription of **speed-ranked, live-tested** proxy configs decoded from NapsternetV / NPV Tunnel (`.npvt`) files harvested from public channels.

Every server is decoded, verified with a live download test, and ranked by throughput before publishing. Each config is name-tagged `<flag> CoreForge Collector 3 NNN`, where the flag is the exit country and `NNN` is the speed rank (`001` = fastest).

## Subscribe

| Format | File |
|--------|------|
| Base64 (v2rayNG / Xray / Hiddify / sing-box) | [`subscription_base64.txt`](subscription_base64.txt) |
| Plaintext | [`subscription_raw.txt`](subscription_raw.txt) |

Subscription URL:

```
https://raw.githubusercontent.com/paranoideveloper/CoreForge-Collector3/main/subscription_base64.txt
```

Rebuilt automatically every few hours.
